# ASNA-2026-GLP-1-Mortality-Model-Build

This repository contains the modelling pipeline for the Green Crest Life Insurance mortality prediction challenge (Round 1). The objective is to predict the probability of death within the next 5 years for policyholders, specifically analyzing how emerging GLP-1 adoption and policyholder characteristics impact long-term mortality risk.

** Primary Goal **: Predict the probability of death for each policyholder in the test set.
